# Telegram NFT Escrow Bot

Безопасный Telegram-бот для сделок NFT-подарков.

## Стек

- Python 3.12
- aiogram 3.x
- PostgreSQL
- SQLAlchemy
- Alembic
- Redis FSM
- Docker / Docker Compose

## Быстрый старт

1. Скопируйте `.env.example` в `.env` и заполните поля.
2. Запустите контейнеры:

```bash
docker compose up --build
```

3. Инициализируйте базу данных:

```bash
docker compose exec bot python -m app.db.migrate
```

4. Запустите бота локально или в контейнере.

## Команды

- `/start` — главное меню
- `/admin` — админ-панель (только для ADMIN_ID)
- `/deals` — список сделок (админу)
- `/payments` — проверки оплат (админу)
- `/withdraws` — заявки на вывод (админу)
- `/users` — список пользователей (админу)
- `/stats` — статистика (админу)
- `/broadcast` — рассылка (админу)
- `/canceldeal <id>` — отмена сделки (админу)
- `/finishdeal <id>` — принудительное завершение сделки (админу)

## Структура проекта

- `app.main` — запуск бота
- `app/bot/` — обработчики, клавиатуры, состояния
- `app/db/` — модели, репозитории, миграции
- `app/core/` — конфиг и логирование

## Примечания

Бот работает локально на вашем ноутбуке: если ноутбук выключен, бот не работает; если включен — бот работает.
